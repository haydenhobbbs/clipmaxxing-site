Clip Maxxing Uploader

A private tool for the Clip Maxxing YouTube channel

Clip Maxxing Uploader is a personal tool used by the owner of the Clip Maxxing YouTube channel. It turns livestreams from creators who allow clipping (for example through paid clipping campaigns) into short vertical clips, sends each clip to the channel owner to review, and uploads only the clips the owner approves to the owner's own channel.

How it uses YouTube

  • Uploads approved clips to the owner's own YouTube channel (YouTube Data API).
  • Reads the owner's own channel and video statistics to see which clips perform well (YouTube Analytics API).

The only account that signs in to this tool is the channel owner's. It is not offered to other users.

Uses YouTube API Services. This app uploads to and reads data from YouTube through the YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is covered by the Google Privacy Policy.
